# 反转锚点控制器 v2 · 2026-10-08

本次修正以用户明确授权为准，解决旧控制器在非极端折返中沿下边界原路返回的问题。算法版本为 `pivot-hysteresis-v2`，公开策略标识为 `finite-rational-pivot-v2-60-rho0.9`。

## 数学定义

`S_Tech` 越高越便宜；其他基本面固定时 `S_Tech=C/P`。公开百分位已取反：
`x=1-count(S_history<S_current)/59`，所以 x=0 最便宜、x=1 最昂贵。

保留原形状 `f(t)=0.1t²/(1-0.9t)`、杠杆归一化 `z=(L-1)/0.75` 和硬包络：

- 下边界 `lo(x)=f(1-x)`；上边界 `hi(x)=1-f(x)`。
- 每次转向记录反转点 `(a,za)=(previous_x,z)`。
- x 升高：`z_raw=za*[1-f((x-a)/(1-a))]`，通向 `(1,0)`。
- x 降低：`z_raw=za+(1-za)*f((a-x)/a)`，通向 `(0,1)`。
- 信号不变时保留原状态，转向容差仍为 `1e-12`。
- `z=clip(z_raw,lo(x),hi(x))`，`L=1+0.75z`。

代码处理端点分母和浮点误差。`direction=up/down` 仍描述内部便宜程度 `u=1-x`。
`alpha/beta` 保留用于审计兼容，新控制器实际使用 `pivot_x/pivot_z`。

首次入场仍严格为 x<30%，初始化仍在下边界。进入稳定回环前可能存在状态漂移，并非每次首次折返都已闭合。
稳定局部回环中，估值升高路径的杠杆高于估值降低路径，修正原红色回落路径高于绿色回升路径的负积分方向。
缩放曲线触及包络时必须裁剪，裁剪处不保持严格同形。

## 本项目的状态升级

公开数据格式为 schema 4，独立于控制器的 v2 版本。估值、价格、汇率和逐标的正式状态改为仓库文件；本次市值或比例仅在内存中使用。

- 支持读取原算法的 schema 1/2 备份及兼容的 pivot v2 schema 2 备份。
- 只提取公开估值修订、价格、汇率及来源证据，丢弃账户、持仓、融资及自动任务。
- 原算法的正式事件只保留标的重放提示，不保留可能关联账户的旧原始载荷，不激活旧 pending target。
- 首次生成新版正式信号时，对有旧事件的标的重放截至信号月份的估值历史，之后持久化新版锚点。
- 新版正式事件必须与全部固定配置一致，且具有有效反转锚点；恢复后继续计算应与未中断路径相同。
- 临时回放使用新控制器，但不改正式状态。月末 pending target 与次月激活仍分离，不执行交易。

60 个月窗口、rho=0.9、1–1.75 倍目标、2.25 倍硬上限、5.3% 年融资率、0.05% 单边费用不调参。日常组合只输入市值或比例；异币种换算使用人工维护的汇率。

## 收益验证的边界

在立即再平衡、无费用/融资成本、价格路径有限变差且 `ln(P)=kx` 的理想情形，闭合回环的对数收益是 `k∮L dx`。
真实 x 是滚动排名，不是价格；盈利预测和增长等变化也会改变 x。即使稳定回环积分为正，也不能直接当作实际净利润。

`scripts/validate-oscillation.mjs` 使用本项目真实估值公式、滚动百分位、控制器和账户公式，保留冻结的旧控制器作为对照。
四个场景预先规定，不搜索参数：60 个月准备期之后 120 个月周期价格，基本面固定，各候选同一合格入场。
月末信号在次月首个平日收盘后激活，该日先用旧目标；合成价格按平日收盘对数插值，利息按日历天数计提，计入交易费用及硬上限。没有独立跳空或交易所节假日模型。
截断价格序列后的信号/净值前缀与完整运行一致，检查无未来数据。原始结果及源码哈希见 [合成报告](oscillation-v2-report.json)。

较大震荡改善，小幅震荡不一定优于旧版，极小幅震荡仍亏损。
将价格路径振幅压缩可以保持排名顺序及目标杠杆不变，却使价格收益趋近零；融资成本仍为正。因此只有百分位输入的控制器无法保证每种震荡都净盈利。
