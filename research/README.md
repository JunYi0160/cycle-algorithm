# 独立数学策略：冻结样例包 v1

本包把四种数学思路具体化为 11 个候选策略，供后续回测复用。另提供 5 个基准、14 条确定性合成路径，以及无费用/含费用两套结果。候选没有按这些路径的结果调参。

这是独立研究模块；原有 `src/strategy.js` 和生产入口保持原状。样例中的 `SYNTH` 是合成资产，日期仅表示观察顺序，结果不是证券历史回测。

## 文件与运行

| 文件 | 用途 |
|---|---|
| `candidates.json` | 冻结参数、策略 ID 和基准 |
| `strategies.mjs` | 可导入的策略实现与账户核算 |
| `examples.json` | 14 条价格路径，可替换为后续回测输入 |
| `run-examples.mjs` | 对相同起点运行所有适用候选 |
| `examples-report.json` | 自动生成的摘要、逐步仓位、交易及数学诊断 |
| `strategies.test.mjs` | 手算例子、收益恒等式、资金守恒和无前视检查 |

在项目根目录运行：

```powershell
node --test research/strategies.test.mjs
node research/run-examples.mjs
```

## 统一账户与执行规则

- 初始资金为 10,000，价格锚点在共同入场时一次性确定。
- 单边交易成本为成交金额的 0.05%；另运行费用为零的数学对照。
- 允许小数单位；全部候选不借款、不做空，现金收益为零。
- 输入每行包含 `date`、`prices`，可另设 `rebalance: false`。第一行初始化并交易；随后仅在预先指定的交易行调仓，其他行只更新市值。
- `prices` 是该时点已经可观察的可成交价格向量。合成模型假定立即成交；真实历史回测需要明确实际成交时点、滑点和延迟。
- 最后一行同样按其 `rebalance` 字段处理，随后按市值计净值；没有强制清仓。因此默认例子包含末行调仓费用，但不包含全部卖出的清仓费用。
- 所有账户股票及现金始终计入净值；网格另列已实现利润和未完成库存浮动盈亏。
- `max_drawdown_at_observations` 仅为输入观察点之间的最大回撤。月度输入不能被解释为日内或逐日最大回撤。
- 成交记录 `trades` 为每个资产的买卖金额，正数买入、负数卖出；`units` 为持有单位。

单股再平衡采用的费用方程是：

\[
E_{after}=E_{before}-c\left|wE_{after}-A_{before}\right|.
\]

多股版本统一解：

\[
E_{after}+c\sum_i\left|w_iE_{after}-A_{i,before}\right|=E_{before}.
\]

因此目标权重基于扣除费用后的净值，不会偷偷借款支付费用。

## 1. 凹函数生成仓位：三个具体实例

令入场价为 \(P_0\)，固定锚点 \(K_j=m_jP_0\)，使用：

\[
F(P)=\sum_j a_j\frac{P}{P+K_j},\qquad
w(P)=\frac{PF'(P)}{F(P)}.
\]

| ID | 冻结函数/锚点 | 入场股票仓位 | 研究目的 |
|---|---|---:|---|
| P-R1 | \(F=P/(P+P_0)\) | 50.00% | 基础价格循环候选 |
| P-R2 | \(F=P/(P+2P_0)\) | 66.67% | 更高持股比例的独立候选 |
| P-MIX | \(F=\frac12P/(P+0.5P_0)+\frac12P/(P+2P_0)\) | 44.44% | 将曲率分布在两个价格尺度上 |

锚点永不随滚动价格、盈利预期或后来公布的估值改写。系数为正，因此三个函数均正、递增、凹；仓位处于 0–100%。固定尺度不等于企业真实价值。

例：入场价 100。P-R1 在价格 80、100、120、200 时的目标股票仓位依次为 55.56%、50%、45.45%、33.33%。P-R2 对应 71.43%、66.67%、62.50%、50%。

数学检查项：

\[
D_t=F(P_t)+F'(P_t)(P_{t+1}-P_t)-F(P_{t+1})\ge0,
\]

\[
\log(W_T/W_0)
=\log(F(P_T)/F(P_0))
+\sum_t\log(1+D_t/F(P_{t+1}))
+\sum_t\log\eta_t.
\]

\(\eta_t\) 是每次扣费的净值保留比例。这里只在实际调仓点划分收益区间，标记为不调仓的中间行不会虚构额外波动收益。报告包含端点项、累积差额项、费用项和恒等式残差。

手算验收：P-R1 无费用，100 → 120 → 100，终值 10,166.666667；100 → 80 → 100，终值 10,250。B-50 是固定 50% 股票仓位对照，前一条路径终值 10,083.333333。

## 2. 有限批次与锁存利润：三个跨度

每个候选预留 40% 初始资金为现金，剩余 60% 分成 5 个交易批次。每批预算均为 1,200，包含买入费用。

\[
L_j=P_0/(1+s)^j,\quad H_j=(1+s)L_j,\quad j=0,\ldots,4.
\]

\[
q_j=1200/[(1+c)L_j].
\]

| ID | 价格跨度 \(s\) | 入场价 100 时的五个买入阈值 | 五个卖出阈值 |
|---|---:|---|---|
| G-05 | 5% | 100, 95.2381, 90.7029, 86.3838, 82.2702 | 105, 100, 95.2381, 90.7029, 86.3838 |
| G-10 | 10% | 100, 90.9091, 82.6446, 75.1315, 68.3013 | 110, 100, 90.9091, 82.6446, 75.1315 |
| G-20 | 20% | 100, 83.3333, 69.4444, 57.8704, 48.2253 | 120, 100, 83.3333, 69.4444, 57.8704 |

每批的机械规则：

1. 空仓且交易时点价格不高于买入阈值，买入预先确定的单位数。
2. 持仓且交易时点价格不低于卖出阈值，卖出整个批次。
3. 净利润移至独立现金账本；该批交易预算恢复为原 1,200。
4. 每批每个观察点至多执行一次交易；无持仓时不会凭空产生卖出。

跳空时使用观察点的实际价格，不假定在途中各阈值成交，不借助日内高低价虚构顺序。买入更低时，单位数保持原计划，未花完预算留在该批现金中。阈值比较仅设相对 \(10^{-12}\) 的浮点边界容差。

完整账户满足：

\[
W_t=W_0+\Pi_{locked}(t)+U_{open}(t),
\]

\[
W_t\ge4000+\Pi_{locked}(t).
\]

资金下界依赖无借款、正价格、利润不再投入及现金收益为零等本包规则。开放库存仍可能大幅浮亏。

手算验收：G-10，100 → 110，第一批单位数为 \(1200/[100(1.0005)]\)，完成后的净利润为 118.68065967，账户终值为 10,118.68065967。100 → 1 则必须报告未完成批次浮亏，不允许仅报告实现利润。

## 3. 熵生成组合：三个强度

适用于至少两个资产。入场时建立等金额、固定单位数的被动基准：

\[
b_i=W_0/(nP_{i,0}),\quad B_t=\sum_i b_iP_{i,t},\quad
\mu_{i,t}=b_iP_{i,t}/B_t.
\]

\[
H(\mu)=-\sum_i\mu_i\log\mu_i,\quad
\pi_i=\frac{\mu_i(c-\log\mu_i)}{c+H(\mu)}.
\]

| ID | \(c\) | A、B 从 100/100 变为 120/80 时的 A 目标权重 | 研究目的 |
|---|---:|---:|---|
| E-025 | 0.25 | 49.4572% | 较强的相对权重再平衡 |
| E-1 | 1 | 54.1834% | 中等强度 |
| E-4 | 4 | 57.9176% | 更接近固定单位数被动基准 |

此时被动基准 A 权重为 60%。三个候选入场时均为等权，之后总股票仓位均为 100%。这里的 \(c\) 是熵参数，不是交易成本；代码和参数文件分别使用 `c` 与 `one_way_cost`。

数学检查项：令 \(G=c+H\)，相对净值 \(R=W/B\)，则：

\[
\log(R_T/R_0)=\log(G(\mu_T)/G(\mu_0))
+\sum_t\log\left(1+\frac{KL(\mu_{t+1}\Vert\mu_t)}{G(\mu_{t+1})}\right)
+\sum_t\log\eta_t.
\]

报告同时保存基准净值、基准权重、绝对净值、相对净值及分解残差。固定基准不受实际策略调仓影响。

手算验收：A、B 为 100/100 → 120/80 → 100/100，三个无费用候选均产生正收益；100/100 → 80/80 → 60/60，三个无费用候选均亏损 40%，散度项为零。该组下跌案例检验相对收益与绝对收益的区别。

## 4. 资本混合：单股和多股两个实例

| ID | 成员 | 初始分配 |
|---|---|---|
| M-SINGLE | P-R1 + G-10 + B-STOCK | 各 1/3 |
| M-MULTI | E-025 + E-1 + E-4 + B-EQUAL-HOLD | 各 1/4 |

每个成员独立运行、独立支付费用；成员之间没有资金转移。总净值和费用为各成员账本之和。权重仅由成员自身净值增长自然改变，不使用事后最佳策略重新分配历史资金，也不假定净额合并交易自动减少费用。

规模线性的比例费用模型下，与所有成员从相同完整本金单独运行的终值比较：

\[
W^{mix}_T=\frac1M\sum_kW^{(k)}_T\ge\frac1M\max_kW^{(k)}_T.
\]

报告保存每个成员的净值、资金份额、等初始资金的最佳成员净值和竞争下界。此界可以很松，混合策略不保证优于每个成员。

## 五个基准

- B-CASH：100% 无息现金。
- B-STOCK：单股买入后固定单位数持有，含入场费用。
- B-50：单股与现金维持 50%/50%，按相同交易时点再平衡。
- B-EQUAL-HOLD：多股入场等金额，之后固定单位数持有。
- B-EQUAL-MIX：多股维持等权，按相同交易时点再平衡。

原有 1–1.75 倍控制器另行保留在生产模块；本包没有把高杠杆旧策略伪装成相同风险基准。

## 后续历史回测接入

所有策略使用由外部确定的共同入场日期。与当前估值控制器比较时，先按同一估值序列、同一有效历史窗口及严格 `x < 0.30` 的规则选共同信号日，再使用相同的实际执行起点。多资产比较应先固定完整资产集合和共同可用日期。预热数据可以计算信号，策略状态及锚点只在共同入场初始化。

候选支持预先固定的每日、每周或每月调仓计划；统一传入 `rebalance` 布尔标记。没有预先指定频率的研究结果不可互相比排名。本文件中的小路径每个默认交易行都是可成交时点，不代表采用月末收盘产生信号后又按同一收盘价成交。

真实数据需要明确价格单位：

- 若输入拆股调整但不含分红的价格，本包输出为不含分红的账户表现。
- 若输入可投资的总收益指数作为价格代理，`units` 是该总收益资产的指数单位，代表所持股票部分自动再投资分红；它不是原始股票实际股数。
- 若要模拟原始股票股数、现金分红、实际拆股和不同账户现金收益，需要在本包之外加入对应的公司行动和现金账本。不要把不同口径混用后解释为真实账户收益。

导入方式：

```javascript
import {simulate} from './research/strategies.mjs';

const rows = [
  {date: '2020-01-02', prices: [100]},
  {date: '2020-01-03', prices: [105], rebalance: false},
  {date: '2020-02-03', prices: [120]},
  {date: '2020-03-02', prices: [100]}
];
const result = simulate('P-R1', rows, {capital: 10000, cost: 0.0005});
```

也可以复制 `examples.json` 的结构，填写实际数据来源说明和 `scenarios`，每个场景显式指定 `strategy_ids`，然后执行：

```powershell
node research/run-examples.mjs --input research/my-history.json --output research/my-history-report.json
```

数据缺失、非正价格、资产数改变或日期不递增会报错；不会静默剔除资产或填造价格。默认不包含税、滑点之外的独立点差、延迟执行残差或现金利息；本包费用设置仅为比例成本模型。

后续比较应记录净收益、观察频率对应的最大回撤、股票敞口、换手、费用、未完成库存及利润来源。先冻结候选、参数和数据规则再评价；修改参数时创建新版本，保留原始结果。报告附带参数和执行器源码哈希以及输入内容哈希，方便重现。

## 数学来源

- Fernholz 与 Karatzas：[Stochastic Portfolio Theory: an Overview](https://www.math.columbia.edu/~ik/FernKarSPT.pdf)，熵组合与函数生成框架。
- Pal 与 Wong：[The geometry of relative arbitrage](https://arxiv.org/abs/1402.3720)，离散路径、凹函数与相对收益结构。
- Cover：[Universal Portfolios](https://isl.stanford.edu/~cover/papers/universal_portfolios.pdf)，资本混合与长期竞争的研究背景；本包有限成员界来自直接求和。

数学恒等式和合成路径通过验收，不等于已证明真实证券的样本外净收益优于现有算法。
