# Cycle Algorithm · 浏览器版

静态网页在浏览器中计算策略。日常运行不需要旧数据库、Docker 或 Python；新版没有券商连接与自动交易功能。账户、持仓、估值修订和正式状态保存到当前浏览器的网站存储中。

## 本地运行

需要 Node.js 22 或以上，无须安装应用依赖。在克隆的仓库根目录打开终端（本机为 `D:\Documents\GitHub\cycle-algorithm`）：

```powershell
node --test tests/*.test.mjs
node scripts/build.mjs
node scripts/serve.mjs
```

打开 `http://127.0.0.1:8788/cycle-algorithm/`。预览服务只提供静态文件；部署后由 GitHub Pages 提供同样的文件。本地预览地址和线上地址的浏览器存储分别独立，需要用完整 JSON 备份迁移。

也可使用 `npm test`、`npm run build`、`npm run preview`。构建输出为 `dist/`，相对路径同时适用于域名根目录和 GitHub Pages 项目子路径。部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 日常操作

1. 在“账户与持仓”填基础币种、融资余额和各持仓数量、市值。市值必须事先换算为基础币种。股票市值 A 自动取持仓合计；B 为正表示借款，为负表示现金；E=A−B 必须为正。保存后显示实际与回放目标杠杆和市值差额。
2. 导入历史评分 CSV / JSON，或逐月输入 S_Tech。至少有覆盖 60 个月的历史，才可回放。内部缺月仅临时线性插值，不做两端外推，也不保存为原始记录。来源已经插值的月份另作标记。
3. 点击标的“临时计算并可视化”查看历史。没有 x<30% 入场点时，回放会强制从最早可计算月入场，并显示提示。这个规则只用于预览。
4. 如需持续记录真实正式信号，在“正式月末信号与激活”生成月末信号。正式入场严格为 x<30%，不强制入场、不补月。先生成 pending target，再到下一月首个交易日收盘后手动激活为 current target。应用校验月份和日期先后；交易所日历及具体收盘时间由用户核实。
5. 定期“下载完整 JSON 备份”。恢复时先展示记录数量，再由页面中的恢复按钮替换本地数据。清理浏览器、换设备、换网址前必须导出；没有自动同步。

主界面组合目标仍来自各持仓历史预览，再按正市值加权，不使用正式 current target 代替它。任何非零持仓缺少历史、类型不支持或市值无效，都会阻塞组合结果，不会剔除它再重新分配权重。空头会在账户保存时被拒绝，期权及其他类型会明确阻塞策略。

顶部调整金额沿用 `目标市值=净值×目标杠杆`，显示差额不含手续费。“含交易费用的精确再平衡金额”单独调用核心费用公式。2.25× 硬上限只给提示，不执行交易。

## 估值格式

CSV 表头：

```csv
symbol,valuation_date,s_tech,source_code,notes,interpolated
AAA,2026-09-30,5.3,manual,实际观测,false
```

可以用 `month`（如 `2026-09`）替代 `valuation_date`，会按月末保存。JSON 可以是同样字段的记录数组，或 `{ "valuations": [...] }`。空评分、NaN、Infinity、错误日期和表头会使整个导入失败；不发生半批导入。同日更新保留旧修订，相同记录可重复导入。未来日期不参与截至当天的计算。

“基本面原始输入”保留完整固定算分公式，以及 EPS、收入增长、90 天 EPS 修正和现金质量项。增长率为小数，所有必需输入都要填写；N/A 结果明确展示，不猜值。这里没有移植旧系统 FY1/FY2 原始供应商 CSV 的自动 NTM 派生导入器；该类数据可先用原导入器转换，或在新页面填写完整公式输入。

## 从旧系统迁移

这是一次性只读导出，旧系统必须在导出时可访问。新应用之后不依赖它。

```powershell
cd C:\strategy-directus
python -B browser-app/scripts/export_legacy.py
```

输出默认在 `browser-app/private-exports/legacy-migration-时间.json`。文件只留本机，不进入 `dist/` 或 GitHub。打开新页面，在“恢复完整 JSON 备份”选择该文件。

导出包括估值全部修订、来源、原始算分输入、最新账户对应的持仓，以及与当前参数一致的正式策略事件。持仓市值按同一账户快照中保存的 ExchangeRate 换算为基础币种，并保留原币种市值、汇率及快照时间；缺少币种或汇率时停止导出，不猜测换汇。旧版不兼容控制器不会转换为新状态，旧事件仍留在原数据库。换算后持仓合计与旧账户 A 存在差异时，新 A 用持仓合计、B=A−E 保留旧净值，迁移说明会列出原值，用户应核对。

汇率口径依据：[IBKR Account Value Keys](https://www.interactivebrokers.com/docs/tws-api/doc/account-portfolio-data/account-updates/account-value-keys)，ExchangeRate 是该币种相对账户基础币种的转换率。它只用于一次性旧数据导出，新网页没有券商连接功能。

来源或备注明确标注评分插值的记录会标记为来源插值；仅 EPS 90 天输入插值不会当作整月评分插值。旧数据库未提供独立标志，其余迁入月份标记为“来源待核实”，不宣称为原始观测。备注和来源证据保留，页面中可查看迁移说明。旧系统未启用的标的历史也保留，新版由手动持仓确定计算范围。

数据存储使用有路径命名空间的 localStorage，适合当前月度历史规模。浏览器空间不足或写入被禁用时会提示，保留上一份已保存数据。无法解析已有本地数据时禁止覆盖，可先下载故障恢复文件，再恢复有效备份。

## 代码边界与验证

- `src/strategy.js`：Python 核心的数值移植；百分位、曲线、包络、控制器、账户利息/费用与硬上限。
- `src/valuation.js`：科技成长股固定算分。
- `src/preview.js`：月度整理、临时插值、只读回放、逐持仓计算与组合汇总。
- `src/model.js`：导入校验、修订、账户一致性、正式状态与备份校验。
- `src/storage.js`：本地保存/恢复。
- `src/app.js`：页面事件与展示；不定义策略公式。

`tests/fixtures/python-baseline.json` 是用当前 Python 源码生成的公开、虚构测试数据，包含源码 SHA-256。测试覆盖 1,475 步控制器路径、101 个曲线/包络点、严格排名及相同评分、入场与激活、转向、端点、边界裁剪、状态恢复、利息、手续费、硬上限、完整回放，以及组合/账户/备份。旧源码存在时会核对哈希，防止拿过期基准比较。

重新生成基准：

```powershell
python -B scripts/python_baseline.py --engine ../engine
node --test tests/*.test.mjs
```

可选浏览器集成测试使用开发用 Playwright，不是生产依赖。先启动预览，再在另一终端运行：

```powershell
npm install --no-save --package-lock=false playwright
node tests/browser-smoke.mjs
```

默认使用已安装 Chrome；设置 `PLAYWRIGHT_CHANNEL=msedge` 可使用 Edge。测试使用独立浏览器上下文和虚构数据，验证子路径、桌面/390px 手机布局、手动输入、阻塞、导入、算分、正式状态、备份、刷新与损坏存储恢复。产物保存在被忽略的 `tests/artifacts/`。
